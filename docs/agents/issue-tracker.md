# Issue Tracker

GitHub Issues for `mhuang74/googleads-rs`, via the `gh` CLI.

- **Create**: `gh issue create --title "..." --body-file ... --label ...`
- **Read**: `gh issue view <n>` / `gh issue list --label ...`
- **Blocking edges**: GitHub has no native blocking relationship — record each ticket's blockers in the issue body ("Blocked by" section) and reference the real issue numbers once published.
- **PRs as a request surface**: off

Parent issues (e.g. the upgrade-automation spec) are never closed or modified by ticketing skills.
